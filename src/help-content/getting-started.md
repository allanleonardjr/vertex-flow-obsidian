# Getting started

Vertex Flow brings a Linear-style task manager into your vault. Projects and
Tasks are plain Markdown notes — you can read and edit them like any other
note, and Vertex Flow keeps its own views in sync automatically.

**To begin:**

1. Create a workspace from the sidebar's **Workspaces** section (or open a
   bundled sample workspace from the template gallery to look around first).
2. Add a Project, then a Task inside it.
3. Switch between **List** and **Board** from the view bar above the task list.
