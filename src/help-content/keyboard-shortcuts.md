# Keyboard shortcuts

| Action | Shortcut |
| --- | --- |
| Move focus | Arrow keys, or `j` / `k` |
| Move between board columns | `←` / `→`, or `h` / `l` |
| Open focused task | Enter |
| Open the raw Markdown note | `o` |
| Jump to parent task (or project) | `p` |
| Jump to first sub-task | `s` |
| New task | `c` |
| Add to selection | `x` |
| Select all | Cmd/Ctrl + `a` |
| Archive / unarchive focused (or selected) | `e` |
| Close tab | Esc |
| Close all task tabs | Shift + Esc |
| Quick capture | Command palette → "Quick capture: new task" |

Every plugin action is also registered as an Obsidian command, so you can
rebind any of them from Obsidian's own Hotkeys settings.
