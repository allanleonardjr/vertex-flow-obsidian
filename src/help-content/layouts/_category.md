A **layout** is *how* a view paints its tasks. The five layouts here render the
same filters, grouping, sort, and Saved Views from the same engine — only the
presentation changes. Layouts belong to views: any view (a [**Saved
View**](help://views-saved-views), a system or hub view, a Project's view) can
be flipped between them from the view bar. See [**Views**](help://views) for
what a view is.
