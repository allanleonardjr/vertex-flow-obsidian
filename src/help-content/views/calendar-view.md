---
title: Calendar view
order: 40
---

A month grid that drops each task onto a single day — the day named by one
date field, chosen with the **Due / Start** toggle in the toolbar. A task with
no value in that field sits in the collapsible **Unscheduled** drawer until you
drag it onto a day.

Drag a chip to another day to reschedule it: a task carrying both a start and a
due date keeps the gap between them, exactly like moving a Timeline bar. Click
an empty spot in a day to create a task already dated to it. A day with more
tasks than fit shows **+N more**, which opens the rest in a popover.

Prev / next month and **Today** just page the grid — they never count as
unsaved changes. The date-field toggle does change what the view shows, so it
saves like grouping or sort. Projects don't appear on the Calendar.
